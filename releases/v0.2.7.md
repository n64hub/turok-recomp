An update of the renderer and runtime every recomp of this project shares.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `TurokRecompiled-v0.2.7-windows-x64.zip` and run `TurokRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `TurokRecompiled-v0.2.7-linux-x64.tar.gz` and run `TurokRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 8 MiB, SHA-1 `40fb0250c095740031278fb1f82b9937a3895e01`): pick it with **Load ROM**, then **Start Game**.

**Fixed:**

- The picture's bottom row is drawn at every window size.
- A frame is no longer shown while it is still being drawn, which could leave out what the game draws last in it.

These come with N64Recomp-browser v0.205.0's renderer and runtime.

**Not checked yet:** the levels past the first one's start, the bosses, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/turok-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-dinosaur-hunter](https://n64hub.com/turok-dinosaur-hunter/).
