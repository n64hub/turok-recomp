An update to Turok: Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- Widescreen: in a window wider than 4:3 the level reaches the window's edges and the HUD sits at its sides (Aspect Ratio, on the Graphics settings; Original keeps the 4:3 picture)
- The renderer and runtime are updated to N64Recomp-browser v0.184.0's; nothing else changes in how the game plays on the desktop, since the fix they bring, which framebuffer a game frame ends on, is the web build's

**Windows:** unzip `TurokRecompiled-v0.1.1-windows-x64.zip` and run `TurokRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `TurokRecompiled-v0.1.1-linux-x64.tar.gz` and run `TurokRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 8 MiB, SHA-1 `40fb0250c095740031278fb1f82b9937a3895e01`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels past the first one's start, the bosses, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/turok-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-dinosaur-hunter](https://n64hub.com/turok-dinosaur-hunter/).
