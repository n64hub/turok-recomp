An update to Turok: Recompiled, for Windows and Linux: its Controller Pak is now the one the recomps' shared runtime has, and the runtime and renderer are updated. Saves made by earlier versions load as before.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Controller Pak:** the game's pak is now the one the web support's runtime has for every recomp, in place of a copy of its own. It is the same file (`saves/controllerpak_1.mpk`), so saves made by earlier versions load as before: a save made with v0.2.10 was loaded and saved over with this version.
- The renderer and runtime are N64Recomp-browser v0.257.0's (from v0.235.0), with the fixes made since for every recomp.

**Windows:** unzip `TurokRecompiled-v0.2.11-windows-x64.zip` and run `TurokRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `TurokRecompiled-v0.2.11-linux-x64.tar.gz` and run `TurokRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release, revision 1.0 (a big-endian `.z64` of 8 MiB, SHA-1 `40fb0250c095740031278fb1f82b9937a3895e01`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the change on Windows (the save was made and loaded on the Linux build), the levels past the first, a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-recomp/issues)), and the Linux build on a GPU other than NVIDIA's.

The same game plays in a browser at [n64hub.com/turok-dinosaur-hunter](https://n64hub.com/turok-dinosaur-hunter/).
