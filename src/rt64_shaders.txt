# The RT64 shaders the web page builds: one shader description a line, other mode L and H, color combiner L and H,
# flags, in hex. RT64 specializes each one's WGSL when the page is built and builds them with the game waiting: those
# above the first "section" line before the game starts, and a section's when the game first draws with its
# shaders, so that nothing draws with the ubershader, which integrated graphics can't afford (N64Recomp-browser's
# docs/porting.md, Prebuilt shader lists).
#
# Recorded by code, not by playing: node lib/N64Recomp-browser/tools/record_shaders.mjs tools/shader_plan.json
# build/web roms/turok1.us.z64 src/rt64_shaders.txt (its header says how), on tools/build_web.sh's page. Section 0 is
# the launcher, the boot (the legal screen, the logos, the intro), the title menu and A through it to a new game,
# reached as a player does (tools/survey.js). Section level1 is the first level: its fly-over, then the player walked,
# turned and firing the bow about it, and the pause menu. Not recorded: the levels past the first's start, the bosses
# and the cutscenes. Flags follow settings (filtering, HDR, MSAA, upscaling), so a change to one of those defaults
# means recording again.
